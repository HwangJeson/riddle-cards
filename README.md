## 수수께끼 단어 카드

상자 속에 숨은 낱말을 힌트를 하나씩 열어 보며 맞히는 게임이에요.

## 동물 숫자 파티

5~6세 아이들을 위한 숫자 맞히기 게임이에요. 두 아이가 번갈아 하면서 별을 모아요.

- 첫째: 더하기 놀이 (두 묶음을 합해서 19까지)
- 둘째: 세기 놀이 (한 묶음을 10까지)
- 동물을 누르면 "하나, 둘, 셋" 하고 같이 세어 줘요
- 신나는 클럽풍 배경음악과 문제 읽어 주기
